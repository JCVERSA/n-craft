# UI asset provenance

These images are bundled locally for decorative use in the operator dashboard; the app does not fetch them from GitHub at runtime.

- `public/assets/minecraft/grass-block.webp` — copied from [JCVERSA/mcassets](https://github.com/JCVERSA/mcassets/blob/62494e6002730c96c0fddaa9f289455522dbd1ce/1790544355275.webp) (source filename `1790544355275.webp`). Displayed as a small world-card accent.
- `public/assets/minecraft/netherrack.png` — Minecraft texture from [InventivetalentDev/minecraft-assets, branch 26.3](https://github.com/InventivetalentDev/minecraft-assets/blob/26.3/assets/minecraft/textures/block/netherrack.png). Used only as a faint Nether-themed background texture; it is not a Bedrock resource pack.
- `public/assets/minecraft/bedrock-nebula-login.webp` — optimized WebP copy of [`bedrock_nebula_bg_1790545818526.jpg`](https://github.com/jcversa17/mc/blob/873904025efb0bfb73fb162dc3aa9e6e1ae5d270/src/assets/images/bedrock_nebula_bg_1790545818526.jpg) from the user-provided visual reference. Used as a decorative login background.
- `public/assets/minecraft/bedrock-world-deployer.webp` — optimized WebP copy of [`bedrock_world_banner_1790545831567.jpg`](https://github.com/jcversa17/mc/blob/873904025efb0bfb73fb162dc3aa9e6e1ae5d270/src/assets/images/bedrock_world_banner_1790545831567.jpg) from the user-provided visual reference. Used as a decorative World Deployer heading background; it does not imply support for any additional world or dimension actions.
- `public/assets/minecraft/creeper-mascot.svg` — locally authored pixel-art vector illustration inspired by the Minecraft Creeper, used on the login screen. No remote sprite or runtime image request is used.
